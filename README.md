**Network Scanner and Log Analyzer**

 **Overview**
This repository contains two basic cybersecurity tools developed using Python:

1. Network Scanner  
   Scans a network or target system to identify active hosts and open ports.

2. Log Analyzer  
   Analyzes log files to detect suspicious activities such as failed login attempts.

---

**Features**

 **Network Scanner**
- Scans target IP addresses
- Detects open ports
- Identifies active devices on the network

  **Log Analyzer**
- Reads and processes log files
- Detects failed login attempts
- Highlights suspicious patterns in logs

---

**Requirements**
- Python 3.x

No external libraries are required (unless you add them later).

---

 **How to Run**
### 1. Network Scanner
Run the following command:
    **python network_scanner.py**

### 2. Log Analyzer
Run the following command:
    **python log_analyzer.py sample_log.txt**

**Example Use Cases**
- Basic network reconnaissance
- Identifying open ports on a system
- Detecting brute-force login attempts from log files
- Learning fundamentals of cybersecurity tools
